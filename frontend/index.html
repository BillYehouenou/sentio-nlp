Comprends ce que ton audience
pensepense, ressent ou retient vraiment.

Colle l'URL d'une vidéo YouTube : Sentio récupère les commentaires, les classe en positif, neutre ou négatif et te rend une analyse claire en quelques secondes.

Aucune inscription requise. 500 commentaires analysés par défaut.

Une lecture fiable, pas une intuition.

Quatre choses qui comptent vraiment quand on analyse les commentaires.

Multilingue

Comprend le français, l'anglais, et les commentaires qui mélangent les deux dans la même phrase.

Le modèle XLM-RoBERTa a été entraîné sur des dizaines de langues à la fois. Il reconnaît aussi bien un commentaire entièrement en anglais qu'un commentaire franglais, sans bascule manuelle ni configuration de ta part.

Rapide

Résultats en quelques secondes, propulsé par une architecture optimisé.

L'inférence tourne via ONNX Runtime plutôt que le framework d'entraînement complet : des centaines de commentaires sont classés en quelques secondes, sans file d'attente ni traitement à surveiller.

Visuel et clair

Des graphiques et des couleurs qui parlent d'un coup d'œil, sans jargon.

Répartition des sentiments, évolution dans le temps, mots-clés qui reviennent le plus : chaque résultat est visualisé directement, pour comprendre l'essentiel sans interpréter un tableau de chiffres.

Sécurisé

Ta clé API n'est jamais exposée, aucune donnée n'est stockée après l'analyse.

La clé API YouTube reste côté serveur, jamais envoyée au navigateur. Chaque analyse est calculée à la volée puis oubliée : aucune base de données, aucun commentaire conservé après l'affichage du résultat.
